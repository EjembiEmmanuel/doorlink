5. AI + ADMIN VERIFICATION WORKFLOW

Every user-submitted manual must go through verification BEFORE becoming publicly searchable.

Workflow:

User uploads manual
↓
System validates file
↓
AI/document verification checks the file
↓
Submission enters admin review
↓
Admin approves or rejects
↓
If approved → manual becomes available in User Manuals
↓
If rejected → manual remains unpublished

The AI verification should check for things such as:

* Is the uploaded file actually a manual/document?
* Does the document appear legitimate?
* Is there a manufacturer/brand identified?
* Does the model/product information make sense?
* Is the document readable?
* Is the file corrupted?
* Is it obviously unrelated to garage doors, roller shutters, automated gates or related systems?
* Is it potentially a duplicate?
* Does the metadata supplied by the user match the contents of the document?
* Does the document appear to contain suspicious, malicious or inappropriate content?

The AI should NEVER automatically approve a questionable document.

If confidence is low, send it to manual admin review.
